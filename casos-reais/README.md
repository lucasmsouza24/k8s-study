# Casos reais

Problemas reais que você resolveu (ou não conseguiu resolver) no trabalho, registrados com o [template](../templates/caso-real.md). Cada caso liga o **sintoma** que você viu ao **mecanismo** que o explica. Se não souber explicar o mecanismo, o caso aponta qual módulo estudar.

Com o tempo, esta pasta mostra a sua evolução de forma concreta: os primeiros casos terão várias marcações **(lacuna)**, e os mais recentes, nenhuma.

> **Repo público**: nunca registre nomes de empresa, clusters, hosts, IPs, resource groups, nomes de aplicações internas ou segredos. Descreva o problema de forma genérica.

Nome dos arquivos: `AAAA-MM-DD-titulo-curto.md`.
